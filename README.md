## 内容规划

- **Projects / 作品**：实际项目的背景、个人职责、关键取舍与结果。
- **Lab / 实验**：可体验的演示、对照实验与相关代码。
- **Writing / 思考**：技术决策、团队实践、产品与商业分析。
- **Radar / 观察**：前沿 AI 信号、来源、个人判断和待验证问题。
- **About / 关于**：个人经历、PolyU、工作方法与联系入口。

## 内容原则

- 用项目、代码、演示和可核验的结果支撑判断。
- 区分外部资料、个人观点、已验证结果与探索中的假设。
- 保留来源及观点更新，逐步积累自己的实践记录。

## 仓库文件

- `site.config.json`：站点名称、域名、作者、GitHub 与栏目规划；后续页面开发时接入。
- `.gitignore`：排除本地凭据、依赖、构建产物和缓存。
